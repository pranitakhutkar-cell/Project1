# Pranita Khutkar — Personal Portfolio

A responsive one-page portfolio inspired by the visual language of the supplied Project 1 reference: dark editorial interface, EXE-style sections, interactive project cards, skill nodes, responsive navigation and a profile image.

## Files
- index.html
- style.css
- script.js
- images/profile.svg

## Before publishing
1. Replace `YOUR_EMAIL@gmail.com` in `index.html` with your email.
2. Replace `YOUR_GITHUB_LINK` with your GitHub profile URL.
3. Replace `YOUR_LINKEDIN_LINK` with your LinkedIn profile URL.
4. If desired, replace `images/profile.svg` with your own photo and update the image filename in `index.html`.

## Run locally
Open the folder in VS Code and use Live Server on `index.html`.

## Publish
Upload the files to a public GitHub repository and enable GitHub Pages.
